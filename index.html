关于 CHUNIDATA

这是一个非官方 CHUNITHM 成绩查询产品的公开 MVP，目前提供纯前端、本地可用的成绩记录功能。

已实现：响应式页面、录入、搜索、筛选、删除、浏览器本地持久化，以及 GitHub Actions 自动发布。

尚未实现：真实账号登录、国服二维码身份验证、Diving-Fish 成绩获取、实时同步、准确 Rating 计算、微信小程序和广告。

为保护玩家账号，本网站不收集任何登录二维码、密码、Token 或其他访问凭证。

以后接入第三方成绩数据需要核实接口的授权范围和商业使用许可；OAuth 凭证必须放在受保护的服务端。

该操作只删除本设备当前浏览器存储的成绩。
